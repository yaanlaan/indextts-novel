# Indextts-Novel

基于 IndexTTS2 的长文本语音合成工具，适用于制作有声小说等长语音场景。

## 功能说明

项目提供两个主要页面。单句合成页面用于快速测试，可输入一段文本并选择参考音频生成语音，支持参考音频、情感向量、情感描述文本三种情感控制方式，并可调节采样参数。长文本配音页面面向实际制作场景，主要功能如下：

- **文本输入与分句**：支持上传 TXT 文件或直接输入长文本，系统按标点符号和换行自动分句。分句后可在表格中手动编辑，包括删除指定句子、合并选中句子、按每 N 句批量合并，分句最大 Token 数可在高级参数中调节。
- **多角色管理**：可为不同角色各自配置参考音频，角色名称需唯一。每个角色卡片显示名称和可播放的参考音频。在分句列表中通过下拉框为每句指定发声角色，支持"全部使用此角色"或"仅选中句子使用此角色"两种分配方式。角色的增删改会同步更新到分句表，删除角色会清空对应句子的角色分配，重命名会同步更新已分配的句子。
- **生成过程控制**：逐句生成语音，实时显示进度条、当前处理句子、已完成数量。生成过程中可暂停、继续或终止。已完成的句子结果会持久化保存到任务目录，意外中断后可从历史记录恢复继续生成，无需重头开始。
- **音频合并处理**：生成完成后自动合并所有成功句子为单个音频文件。可调节句间静音间隔、淡入时长、淡出时长，并随时重新合并。同时生成包含所有单句音频的 ZIP 包供下载。
- **单句重推与编辑**：可对指定序号的句子重新生成，覆盖原有结果。重推后结果表实时更新。适合对个别不满意的句子单独修复，不必重新生成整篇。
- **历史记录管理**：所有推理任务自动保存为历史记录，包含任务 ID、创建时间、总句数、成功数、状态。可加载任意历史记录继续生成，或直接合并已完成的音频。参考音频、分句、角色分配、情感与采样参数都会随任务一起保存和恢复。

## 安装指南

详细的环境配置请前往 indextts2 源项目查看，或者参考[源项目readme](./indextts-readme.md)。

## 使用方法

```bash
uv run webui.py
```

打开浏览器访问 `http://127.0.0.1:7860`。

## 技术架构

基于 IndexTTS2 自回归零样本语音合成模型，音色与情感解耦，情感表达与时长可控。WebUI 使用 Gradio 构建。
